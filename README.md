# AgriPredict Kenya

**AI-Powered Agricultural Intelligence and Prediction Platform for Kenya**

AgriPredict Kenya is a data-driven platform designed to support farmers, agricultural officers, and researchers through agricultural forecasting, predictive analytics, and decision-support tools.

## Project Modules

### 1. Crop Intelligence
- Crop yield prediction
- Crop suitability analysis
- Harvest estimation
- Fertilizer recommendations
- Crop disease risk screening

### 2. Livestock Intelligence
- Milk production forecasting
- Animal growth and weight estimation
- Feed requirement estimation
- Livestock disease risk screening
- Poultry production analytics

### 3. Weather Intelligence
- Rainfall and temperature forecasting
- Drought risk assessment
- Irrigation planning

### 4. Agricultural Market Intelligence
- Agricultural price forecasting
- Market price comparisons
- Farm profitability analysis

## Technology Stack

- **Frontend:** React and Tailwind CSS
- **Backend:** Python and FastAPI
- **Database:** PostgreSQL
- **Machine Learning:** Scikit-learn and XGBoost
- **Data Analysis:** Pandas and NumPy
- **Visualisation:** Matplotlib, Seaborn and Plotly
- **Development:** VS Code, Google Colab and GitHub
